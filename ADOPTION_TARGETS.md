# Adoption Targets

`@stackline/brace` is relevant to maintained applications and wrappers that still depend on `brace` deep imports.

Observed public usage included projects in these groups:

- Angular editor wrappers;
- React editor and diagram tooling;
- Vue 2 Ace wrappers;
- Nextcloud text editing;
- Jekyll administration;
- API design and visualization applications;
- browser-based algorithm and coding tools.

Outreach must be manual, relevant, and limited to repositories that still use Brace. A migration proposal should include a tested branch, disclose that Stackline maintains the replacement, explain the npm alias option, and avoid mass-generated issues or pull requests.
